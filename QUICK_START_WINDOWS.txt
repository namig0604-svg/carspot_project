📥 ШАГ 1: УСТАНОВКА ПРОГРАММ (15 минут)

  1️⃣  Python 3.11+
     → https://www.python.org/downloads/
     → ☑️ Add Python to PATH (ВАЖНО!)
     → Install Now
     → Перезагрузись

  2️⃣  Docker Desktop
     → https://www.docker.com/products/docker-desktop
     → Нажми Download for Windows
     → Запусти инсталлер
     → Перезагрузись
     → Запусти Docker Desktop (иконка кита)

  3️⃣  Git (опционально)
     → https://git-scm.com/download/win
     → Все настройки по умолчанию

═══════════════════════════════════════════════════════════════

✅ ПРОВЕРКА (2 минуты)

Открой Command Prompt (Win+R → cmd → Enter):

  python --version
  → Должно быть Python 3.11+

  docker --version
  → Должно быть Docker version 20.10+

Если что-то не работает - вернись на Шаг 1!

═══════════════════════════════════════════════════════════════

📁 ШАГ 2: СКОПИРОВАТЬ ФАЙЛЫ (5 минут)

Все файлы которые я создал выше - скопируй в одну папку:

  C:\Users\YourUsername\CarSpot\

Структура должна быть:

  CarSpot/
  ├── app/
  ├── CarSpot-iOS/
  ├── requirements.txt
  ├── docker-compose.yml
  ├── .env
  └── Dockerfile

═══════════════════════════════════════════════════════════════

🚀 ШАГ 3: ЗАПУСТИ БЭКЕНД (5 минут)

1. Открой Command Prompt (Win+R → cmd)

2. Перейди в папку проекта:
   cd C:\Users\YourUsername\CarSpot

3. Запусти Docker:
   docker-compose up

4. Жди пока не увидишь:
   ✅ Database initialized
   ✅ Uvicorn running on http://0.0.0.0:8000

5. Открой браузер:
   http://localhost:8000/docs

Если видишь красивую страницу с API - ✅ ВСЁ РАБОТАЕТ!

═══════════════════════════════════════════════════════════════

🧪 ШАГ 4: ТЕСТИРОВАНИЕ (5 минут)

В браузере на http://localhost:8000/docs:

ТЕСТ 1: Регистрация
  → Нажми POST /api/users/register
  → Нажми "Try it out"
  → Введи:
  {
    "username": "testuser",
    "email": "test@example.com",
    "password": "test123456",
    "country": "Georgia"
  }
  → Нажми Execute
  → Если 200 OK - ✅ РАБОТАЕТ!

ТЕСТ 2: Вход
  → Нажми POST /api/users/login
  → Введи:
  {
    "email": "test@example.com",
    "password": "test123456"
  }
  → Скопируй access_token (потом пригодится)

ТЕСТ 3: Создание события
  → Нажми POST /api/events/
  → Нажми "Authorize" (вверху)
  → Введи: Bearer [скопированный_токен]
  → Нажми Authorize
  → Нажми "Try it out"
  → Введи:
  {
    "title": "Friday Night Racing",
    "event_type": "racing",
    "country": "Georgia",
    "city": "Tbilisi",
    "location_name": "Tbilisi Center",
    "latitude": 41.7151,
    "longitude": 44.7671,
    "event_date": "2024-12-20T20:00:00",
    "event_time": "20:00",
    "duration_minutes": 120
  }
  → Нажми Execute
  → Если 200 OK - ✅ СОБЫТИЕ СОЗДАНО!

🎯 ШАГ 5: ПОНИМАЙ ЧТО ТЫ ДЕЛАЕШЬ

API - это как меню ресторана:
  GET  - смотреть (получить данные)
  POST - создать новое
  PUT  - изменить
  DELETE - удалить

Примеры:

  GET /api/events/
  → Получить список всех событий
  
  POST /api/events/
  → Создать новое событие
  
  GET /api/users/me
  → Получить мой профиль (нужен токен!)
  
  POST /api/events/{id}/join
  → Присоединиться к событию

⚠️  ЕСЛИ ЧТО-ТО СЛОМАЛОСЬ

Проблема: "Docker is not running"
Решение: Запусти Docker Desktop (Start → Docker Desktop)

Проблема: "Connection refused"
Решение: Убедись что Command Prompt с docker-compose открыт!

Проблема: "Port 5432 already in use"
Решение: 
  docker ps
  docker kill <container_id>
  docker-compose up

Проблема: "Module not found"
Решение:
  pip install -r requirements.txt
  docker-compose down
  docker-compose up --build
