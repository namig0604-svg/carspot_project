requirements.txt
  → Список всех Python библиотек которые нужны
  → fastapi, sqlalchemy, psycopg2, pydantic и т.д.
  → Docker автоматически установит всё отсюда

docker-compose.yml
  → Инструкция для Docker
  → Запускает PostgreSQL базу данных
  → Запускает Python API сервер
  → Связывает их между собой

Dockerfile
  → Инструкция как собрать Docker образ
  → Копирует Python код
  → Устанавливает зависимости

.env
  → Переменные окружения (чувствительные данные)
  → DATABASE_URL (подключение к БД)
  → SECRET_KEY (для JWT токенов)
  → DEBUG (режим разработки)

README.md
  → Описание проекта
  → Быстрый старт
  → Структура папок

INSTALLATION.md
  → Полная инструкция установки
  → Для всех операционных систем

WINDOWS_SETUP.md
  → Пошаговая инструкция для Windows
  → Решение проблем
  → Как тестировать API

QUICK_START_WINDOWS.txt
  → Очень быстрый старт
  → Основные команды
  → Важная информация в одном файле

🐍 БЭКЕНД PYTHON ФАЙЛЫ (копируй в C:\CarSpot\app\)
═══════════════════════════════════════════════════════════════

app/__init__.py
  → Инициализация пакета app
  → Импортирует основные компоненты

app/main.py ⭐ ГЛАВНЫЙ ФАЙЛ
  → Создаёт FastAPI приложение
  → Подключает маршруты (routes)
  → Запускает сервер на порте 8000
  → Инициализирует БД
  → Добавляет CORS middleware

app/config.py
  → Все настройки приложения
  → DATABASE_URL
  → JWT SECRET_KEY
  → ALLOWED_ORIGINS для CORS
  → MAX_UPLOAD_SIZE и т.д.

app/database.py
  → Подключение к PostgreSQL
  → SQLAlchemy SessionLocal
  → Функция init_db() для создания таблиц
  → Зависимость get_db() для API endpoints

ПАПКА: app/models/ (копируй в C:\CarSpot\app\models\)
═══════════════════════════════════════════════════════════════

app/models/__init__.py
  → Импортирует все модели
  → Экспортирует User, Event, Photo и т.д.

app/models/user.py
  → Модель User (таблица users в БД)
  → Поля: id, username, email, password, avatar_url и т.д.
  → Система премиум подписки
  → Статистика юзера

app/models/event.py
  → Модель Event (таблица events)
  → Поля: title, description, location, latitude, longitude
  → Тип события: racing, photo_session, auto_meetup
  → Модель EventParticipant (кто участвует)

app/models/photo.py
  → Модель Photo (фото с событий)
  → Поля: photo_url, caption, description
  → Модель PhotoLike (лайки фотографий)
  → Модель PhotoComment (комментарии)

app/models/rating.py
  → Модель EventRating (оценки событий)
  → Модель SpotRating (оценки локаций)
  → Модель UserRating (оценки юзеров)
  → Все с полями 1-5 звёзд и отзывы

═══════════════════════════════════════════════════════════════

app/schemas/__init__.py
  → Импортирует все Pydantic схемы

app/schemas/user.py

app/schemas/event.py

app/schemas/rating.py

  → Все с валидацией полей

ПАПКА: app/api/ (копируй в C:\CarSpot\app\api\)
═══════════════════════════════════════════════════════════════

app/api/__init__.py
  → Импортирует все API роутеры

app/api/users.py
  → Endpoints для пользователей:
  → POST /api/users/register (регистрация)
  → POST /api/users/login (вход)
  → GET /api/users/me (мой профиль)
  → PUT /api/users/me (изменить профиль)
  → GET /api/users/{user_id} (чужой профиль)

app/api/events.py
  → Endpoints для событий:
  → GET /api/events/ (список)
  → POST /api/events/ (создать)
  → GET /api/events/{id} (детали)
  → PUT /api/events/{id} (изменить)
  → GET /api/events/map/nearby (на карте)
  → POST /api/events/{id}/join (присоединиться)
  → POST /api/events/{id}/leave (покинуть)

app/api/ratings.py
  → Endpoints для рейтингов:
  → POST /api/ratings/events (оценить событие)
  → POST /api/ratings/spots (оценить место)
  → POST /api/ratings/users (оценить юзера)
  → GET endpoints для получения оценок

ПАПКА: app/utils/ (копируй в C:\CarSpot\app\utils\)
═══════════════════════════════════════════════════════════════

app/utils/__init__.py
  → Импортирует утилиты

app/utils/auth.py
  → Функции для JWT токенов
  → verify_password() - проверка пароля
  → get_password_hash() - хеширование
  → create_access_token() - создание JWT
  → decode_token() - декодирование JWT
  → get_current_user() - зависимость для защиты endpoints
