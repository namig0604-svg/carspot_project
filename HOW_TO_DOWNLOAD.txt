ПРИМЕЧАНИЕ:

Если на Windows файлы .env и .gitignore не видны 
(потому что они начинаются с точки):

1. Откройте File Explorer
2. View → Options → View
3. Включи "Show hidden files"

═══════════════════════════════════════════════════════════════

ДАЛЬШЕ:

После того как все файлы скопированы:

1. Открой Command Prompt
2. Перейди в папку:
   cd C:\CarSpot

3. Запусти:
   docker-compose up
